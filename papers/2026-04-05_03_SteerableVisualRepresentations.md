## 核心信息

### 摘要
预训练的 Vision Transformers（ViTs）如 DINOv2 和 MAE 提供了可以应用于各种下游任务（如检索、分类和分割）的通用图像特征。然而，这些表示倾向于关注图像中最显著的视觉线索，而无法将它们引导向较不突出的兴趣概念。相比之下，多模态 LLM 可以通过文本提示引导，但产生的表示倾向于以语言为中心，并失去其对通用视觉任务的有效性。为了解决这个问题，我们提出了 Steerable Visual Representations（可引导视觉表示），一类可以通过自然语言引导其全局和局部特征的新视觉表示。虽然大多数视觉-语言模型（例如 CLIP）在编码后融合文本与视觉特征（后期融合），我们在视觉编码器的层内通过轻量级交叉注意力（early fusion）直接注入文本。我们引入了用于测量表示引导能力（steerability）的基准，并演示了我们的可引导视觉特征可以专注于图像中的任何期望对象，同时保持底层表示质量。我们的方法还匹配或超越了专门方法在异常检测和个性化对象判别上的表现，在分布外任务中表现出零样本泛化能力。

### 关键贡献
1. **可引导视觉表示（Steerable Visual Representations）**: 一类可以通过自然语言引导全局和局部特征的新视觉表示
2. **早期文本注入（Early Text Injection）**: 在视觉编码器层内通过轻量级交叉注意力直接注入文本
3. **表示引导能力基准**: 引入用于测量表示引导能力的基准
4. **零样本泛化**: 在异常检测和个性化对象判别上匹配或超越专门方法
5. **多模态融合策略**: 早期融合优于后期融合，保持视觉表示质量

## 核心技术

### 问题背景

**现有视觉表示的局限**:
- DINOv2 和 MAE 等预训练 ViT 提供通用图像特征
- 倾向于关注图像中最显著的视觉线索
- 无法引导它们向较不突出的兴趣概念
- 缺乏对特定概念的聚焦能力

**多模态 LLM 的挑战**:
- 可以通过文本提示引导
- 产生的表示倾向于以语言为中心
- 失去对通用视觉任务的有效性
- 过度依赖文本语义

### Steerable Visual Representations 框架

**核心思想**:
通过在视觉编码器的层内直接注入文本（早期融合），实现可引导视觉表示，使全局和局部特征都可以通过自然语言引导。

**技术组件**:

**1. 早期文本注入（Early Text Injection）**:
```
功能：在视觉编码器层内直接注入文本

实现：
- 在 ViT 的特定层中注入文本嵌入
- 通过轻量级交叉注意力机制
- 早期融合（early fusion）

与CLIP的对比：
- CLIP：编码后融合文本与视觉特征（后期融合）
- Steerable Visual Reps：在编码器层内融合（早期融合）
```

**2. 全局和局部特征引导（Global & Local Feature Steering）**:
```
功能：通过自然语言引导全局和局部特征

实现：
- 全局特征：高层语义理解
- 局部特征：细节和对象定位
- 早期注入保持表示质量

优势：
- 可以专注于图像中的任何期望对象
- 同时保持底层表示质量
```

**3. 轻量级交叉注意力（Lightweight Cross-Attention）**:
```
功能：连接文本和视觉特征

实现：
- 轻量级交叉注意力机制
- 计算高效
- 保持表示质量

优势：
- 低计算开销
- 高效融合
```

## 个人思考

### 最有趣的发现
早期融合优于后期融合，这个发现很有趣。传统视觉-语言模型（如 CLIP）使用后期融合，但 Steerable Visual Reps 通过早期融合（在视觉编码器层内直接注入文本）实现了更好的表示质量。

### 最意外的结果
可引导视觉特征可以专注于图像中的任何期望对象，同时保持底层表示质量。这意味着我们可以在不牺牲表示质量的情况下，引导视觉表示关注特定对象。

### 最有价值的启发
可引导视觉表示为 Spatial AGI 提供了灵活的视觉理解能力。分层特征引导（全局 + 局部）为 Spatial AGI 提供了分层空间表示的新思路。
