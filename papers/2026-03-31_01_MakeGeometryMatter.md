## 摘要

本文提出了GeoSR（Geometry-enhanced Spatial Reasoning）框架，旨在解决视觉语言模型（VLMs）在空间推理任务中的局限性。尽管大规模训练赋予了VLMs强大的图像和视频理解能力，但它们在静态场景和动态视频中的空间推理能力仍然有限。

现有研究尝试通过从预训练3D基础模型注入几何token到VLMs中来处理这一限制。然而，作者观察到，这种研究路径中的朴素token融合和标准微调往往导致几何线索在空间推理中被利用不足，因为VLMs倾向于大量依赖2D视觉线索。

GeoSR引入了两个关键组件：
1. **Geometry-Unleashing Masking（几何释放掩蔽）**：在训练期间策略性地掩蔽2D视觉token的一部分，以削弱非几何捷径并强制模型在空间推理时咨询几何token
2. **Geometry-Guided Fusion（几何引导融合）**：一种门控路由机制，在几何证据关键的区域自适应地放大几何token贡献

这两个设计共同释放了几何token在空间推理任务中的潜力。在静态和动态空间推理基准测试上的广泛实验表明，GeoSR始终优于先前方法，通过有效利用几何信息建立了新的最先进性能。

---

## 核心贡献

1. **发现了一个在空间推理中可复现的现象**：在朴素融合和标准微调下，隐式几何注入可能无效。几何token可能被大量忽略，在空间推理中实际收益有限甚至为负。

2. **提出了GeoSR框架**：这是一个简单的框架，鼓励有效且合理地使用几何token。Geometry-Unleashing Masking减少对外观捷径的依赖，Geometry-Guided Fusion在需要几何证据时自适应地路由几何信息。

3. **验证了有效性**：在静态和动态空间推理基准上验证了GeoSR，显示对先前方法的一致改进。

## 核心技术发现

### 1. 几何注入的反直觉现象

研究发现了一个反直觉但可复现的现象：在常见的朴素token融合和标准微调实践中，几何token在空间推理中经常被利用不足。如图1所示：

- **静态场景**：性能增益有限
- **动态视频**：注入几何token甚至可能产生负面影响

这表明模型经常默认使用2D视觉token中的外观驱动捷径，将几何视为可舍弃的辅助信号，而不是空间推理的可行动证据。

### 2. VLM的几何感知框架

传统VLM必须仅从2D视觉token推断场景的3D结构和动态以进行文本提示的空间推理，这可能具有挑战性并导致次优性能。为此，近期方法尝试通过引入几何token来提高VLM的几何感知能力。

**整体架构**（图2）：
- 输入：图像或视频帧序列 {I_t} + 文本提示Q
- 视觉分支：编码图像到2D token F_V
- 提示分支：编码文本到text token F_P
- **几何分支**（新增）：使用预训练3D模型从输入提取几何token F_G
- 融合模块F(·)：合并F_V和F_G形成融合token F
- VLM主干：基于融合token和text token生成答案

**融合方法**：
1. **加性融合**（静态空间推理）：
   F = F_V + MLP(Reshape(F_G))
   
2. **QFormer融合**（动态空间推理）：
   - 首先，使用一组可学习的瓶颈token B通过交叉注意力总结文本提示意图
   F_B = CrossAttn1(B, F_P)
   - 然后，QFormer在这些token中查询几何token
   Z_G = CrossAttn2(F_B, MLP(F_G))
   - 输出附加到视觉token
   F = [F_V, MLP(Z_G)]

### 3. Geometry-Unleashing Masking

**核心挑战**：几何感知VLM仍然可以从2D外观捷径回答空间推理问题，即使提供了几何token。

**解决方案**：引入Geometry-Unleashing Masking在训练期间抑制捷径，强制模型有效使用几何证据。

**掩蔽过程**：
```
F~V = m ⊙ F_V
m_j = {0, if δ=1 ∧ j∈M; 1, otherwise}
δ ∼ Bernoulli(β)
```
其中m是视觉token上的二进制掩码，M是掩码集，β控制训练期间启用掩蔽的概率。

**静态场景（加性融合）**：
- 均匀采样大小为K的掩码集M
- K = ⌈γ(H_V W_V T)⌉
- γ是掩蔽比例

**动态场景（QFormer融合）**：
- 基于查询风格机制选择掩码区域
- 使用注意力权重导出相关性分数s
- 根据分数选择最关键3D token的位置并掩蔽相应的2D视觉token

**TopK选择**：
```
M = TopK(s, K)
K = ⌈γ(H_G W_G T)⌉
```

**相关性分数计算**：
- 使用交叉注意力概率张量A
- 计算每个几何token的平均注意力概率作为相关性度量
- 归一化得到最终相关性分数s

**分辨率对齐**：
如果几何token和视觉token具有不同的空间分辨率，需要进行2D空间插值：
```
F^G' = Interp(F^G, (H_V, W_V))
```

### 4. Geometry-Guided Fusion

**动机**：均匀混合或简单拼接仍然让模型有一个容易的选择来在任何地方降低几何权重并回退到剩余的视觉证据。

**设计**：Geometry-Guided Fusion自适应地控制在每个融合token中注入多少几何证据，在细粒度级别确保几何在信息丰富和必要时占主导地位。

**门控融合权重计算**：
```
α = σ(W_g[V‖G] + b_g)
V = LN_v(F~V)
G = LN_g(F~G)
```
其中[·‖·]表示沿通道维度的拼接，W_g和b_g是可学习参数，σ是sigmoid函数。LN表示层归一化。

α ∈ (0,1)^{(H_V W_V T)×C}，这是一个token和通道级别的门控，实现几何证据的细粒度路由。

**静态空间推理的几何特征**：
```
F~G = MLP(Reshape(F_G))
```

**动态空间推理的几何特征**：
- 紧凑几何证据Z_G首先重新分发回与视觉token对齐的完整时空几何token F^G'
- 使用交叉注意力检索位置感知的细粒度几何特征
```
F~G = CrossAttn3(F^G', Z_G)
```

**自适应融合**：
```
F = α ⊙ V + (1-α) ⊙ G
```

其中⊙表示逐元素乘法。F是融合特征图，在门控α的控制下合理继承视觉和几何线索。

### 5. 实现细节

**静态空间推理**：
- 主干VLM：Qwen2.5-VL-7B
- 预训练3D模型：VGGT
- 掩蔽比例γ=0.8
- 掩蔽启用概率β=0.5
- 训练：1 epoch，Adam优化器，批大小64，学习率1×10^-5
- 推理：禁用掩蔽，馈送完整视觉token

**动态空间推理**：
- 主干VLM：Qwen2.5-VL-7B
- 预训练3D模型：π^3
- 瓶颈长度L_B=32
- 掩蔽比例γ=0.8
- 掩蔽启用概率β=0.5
- 训练：1 epoch，Adam优化器，批大小32，学习率2×10^-7
- 推理：与训练相同，但禁用掩蔽

**计算资源**：
- 4×H200 GPU，每张141GB内存
- 静态推理训练：约14小时（DeepSpeed ZeRO-2）
- 动态推理训练：约20小时（ZeRO-3 Offload）

## 实验结果

### 静态空间推理（VSI-Bench）

**基准**：
- 包含超过5k个QA对，来自288个真实视频
- 主要关注刚性场景，其中相机视角和可见性在帧之间变化
- 包含数值问题和多选题

**数值子任务**：
- 对象计数（Obj. Cnt.）
- 绝对距离估计（Abs. Dist.）
- 对象大小（Obj. Size）
- 房间大小（Room Size）

**多选题子任务**：
- 相对距离（Rel. Dist.）
- 相对方向（Rel. Dir.）
- 路线规划（Route Plan）
- 外观排序（Appr. Order）

**对比基线**：

1. **专有API模型**（强参考）：
   - GPT-4o: 平均43.1
   - Gemini-1.5 Flash: 平均50.8
   - Gemini-1.5 Pro: 平均49.6

2. **通用视频理解模型**：
   - Qwen2.5-VL-7B: 平均40.9
   - LLaVA-Video-7B: 平均48.5
   - InternVL3-78B: 平均71.2

3. **空间推理模型**：
   - Spatial-MLLM: 平均65.3
   - VG-LLM: 平均67.9

**GeoSR性能**：平均68.3

**关键观察**：
- GeoSR在所有子任务上持续改进
- 在数值问题上表现尤为突出（38.7 vs GPT-4o的34.1）
- 在多选题上也达到竞争性性能（57.4 vs InternVL3-78B的44.4）

### 动态空间推理（DSR-Bench）

**基准**：
- 包含1484个QA对，来自575个野外视频
- 由于物体和相机运动，动态空间关系随时间演变
- 正确答案需要时空一致性而非静态线索

**问题类型**：

1. **绝对类型**：
   - 距离（Dist.）
   - 方向（Dir.）
   - 方向（Ori.）
   - 速度（Spd.）
   - 速度比较（Spd. Comp.）
   - 方向预测（Dir. Pred.）

2. **相对类型**：
   - 相对于另一个实体、另一个时间点或另一个参考系定义的关系
   - 包括与绝对类型相似的类型

3. **非模板**：
   - 灵活措辞的问题，不受固定模板限制

**对比基线**：

1. **专有API模型**：
   - GPT-4o: 平均18.8
   - GPT-5: 平均21.1
   - Gemini-2.5-Flash: 平均18.8

2. **通用视频理解模型**：
   - Qwen2.5-VL-7B: 平均18.8
   - Qwen3-VL-8B: 平均23.5
   - LLaVA-Video-7B: 平均22.3

3. **空间推理模型**：
   - VLM-3R: 平均28.2
   - VG-LLM: 平均55.2
   - GSM: 平均87.0

**GeoSR性能**：平均88.0

**关键观察**：
- DSR-Bench对通用模型具有挑战性
- 空间推理模型表现显著更好
- GeoSR与最佳性能模型竞争，在每个子任务类型上获得最高分数
- 几何线索对动态空间推理特别有帮助

### 消融研究

**静态空间推理消融**（表3）：

设置 (a) - 完整GeoSR: 平均68.3
设置 (b) - 用原始融合替换GeoSR融合: 平均67.7
设置 (c) - 保留Geo. Mask，移除Geo. Fus.和Ori. Fus.: 平均68.1
设置 (d) - 移除Geo. Mask，保留Geo. Fus.: 平均68.2
设置 (e) - 仅保留Ori. Fus.: 平均67.2
设置 (f) - 无几何模型: 平均68.6

**分析**：
- 将GeoSR融合替换为原始融合降低性能，表明朴素融合不太有效
- 移除GeoSR融合并保留掩蔽进一步降低性能
- 移除掩蔽但保留融合也导致明显下降
- 仅保留原始融合得到比(d)更差的变体
- 在静态基准上，从(e)到(f)的性能下降相对适度

**动态空间推理消融**（表4）：

设置 (a) - 完整GeoSR: 平均88.0
设置 (b) - 用原始融合替换GeoSR融合: 平均86.7
设置 (c) - 保留Geo. Mask，移除Geo. Fus.和Ori. Fus.: 平均86.7
设置 (d) - 移除Geo. Mask，保留Geo. Fus.: 平均88.0
设置 (e) - 仅保留Ori. Fus.: 平均88.0
设置 (f) - 无几何模型: 平均86.7

**分析**：
- 改进在动态基准上更为明显
- 运动、遮挡使外观线索不太稳定，因此受益于强制的几何依赖和细粒度融合
- 无几何模型(f)在动态基准上甚至优于(e)，表明简单几何token注入在几何线索没有适当控制融合时可能产生负面影响

### 超参数分析

**掩蔽比例γ**：
- γ=0.8: 平均66.1 ✓
- γ=0.6: 平均65.9
- γ=0.4: 平均65.0

**掩蔽启用概率β**：
- β=0.7: 平均64.5
- β=0.5: 平均66.1 ✓
- β=0.3: 平均64.9

**结论**：
- 小γ和β让外观捷径基本保持完整，收益有限
- 过大的β移除太多上下文，可能损害稳定性
- γ=0.8和β=0.5达到良好平衡

### 计算开销

**动态推理在DSR-Bench上**（表6）：

- Qwen2.5-VL-7B: 时间0.37s，大小8.76B，内存18.04GB
- w/ Geo. (Baseline): 时间0.40s，大小9.16B，内存18.81GB
- GeoSR (Ours): 时间0.41s，大小9.23B，内存18.95GB

**结论**：
- GeoSR的额外参数主要来自几何投影和门控模块
- 参数增加相对于几何感知基线较小
- 运行时增加可忽略不计
- 提出的设计高效，不需要大量计算来释放几何线索并提升空间推理性能

## 与Spatial AGI的关系

### 直接贡献

1. **释放了几何信息的潜力**：
   - 论文的核心洞察是：仅仅注入几何token到VLMs中并不足以确保它们被有效利用
   - 这对Spatial AGI至关重要，因为空间智能需要将几何信息作为可行动证据，而不是辅助装饰

2. **从被动到主动几何推理**：
   - 现有方法将几何视为被动辅助信号
   - GeoSR通过Geometry-Unleashing Masking迫使模型主动使用几何信息进行推理
   - 这与Spatial AGI的核心需求一致：系统必须能够主动推理和操作空间信息

3. **自适应几何使用**：
   - Geometry-Guided Fusion提供了细粒度的门控机制，控制何时以及如何使用几何线索
   - 这模仿了人类空间智能：在不同情境下灵活调整对几何线索的依赖程度
   - 对实现鲁棒Spatial AGI至关重要，因为空间信息在不同场景中具有不同的重要性

### 技术启发

1. **掩蔽作为约束机制**：
   - 在训练期间掩蔽2D视觉token迫使模型寻找替代信息源
   - 这种技术可以推广到其他模态，如力、触觉、音频
   - Spatial AGI可以利用类似机制确保多模态系统不过度依赖单一模态

2. **门控融合作为路由机制**：
   - 细粒度门控允许模型在每个token级别决策如何组合不同信息源
   - 这为实现更复杂的多模态融合策略提供了框架
   - 对Spatial AGI特别重要，因为它需要协调视觉、几何、语义、运动等多种模态

3. **问题感知的几何检索**：
   - 在动态场景中，使用QFormer机制检索与问题相关的几何证据
   - 这种注意力驱动的检索可以扩展到更复杂的多步推理
   - Spatial AGI可以利用类似机制从大规模记忆中检索相关信息

4. **对显式3D输入的依赖最小化**：
   - 从单眼视频提取隐式几何token而非依赖显式3D输入（深度、点云、3D地图）
   - 提高了可扩展性和对野外场景的适用性
   - 对实用Spatial AGI系统重要，因为它们需要从常见传感器（如RGB相机）操作

### 应用场景

1. **机器人导航**：
   - 静态空间推理：理解房间布局、物体位置、可达空间
   - 动态空间推理：预测物体运动、规划路径、避免动态障碍物
   - GeoSR的几何感知能力可以增强机器人的空间理解和导航决策

2. **AR/VR交互**：
   - 静态空间推理：理解虚拟物体相对于用户的空间关系
   - 动态空间推理：跟踪用户手势、预测交互轨迹
   - GeoSR可以提供更准确的空间感知，改善沉浸式体验

3. **自动驾驶**：
   - 动态空间推理：预测其他车辆运动、评估碰撞风险、规划安全路线
   - 几何token从单眼视频提取，对实时系统至关重要
   - GeoSR的自适应融合可以在不同驾驶条件下可靠利用几何线索

4. **监控与安防**：
   - 静态空间推理：识别可疑行为的空间模式
   - 动态空间推理：跟踪人员移动、预测潜在威胁
   - GeoSR可以提高异常检测和风险评估的准确性

5. **智能制造**：
   - 静态空间推理：理解装配关系、工具可达性
   - 动态空间推理：监控机器人操作、预测流程效率
   - GeoSR可以增强工业自动化系统的空间智能

## 个人思考

### 最有趣的发现

**几何token的"懒惰使用"现象**：
- 这个发现完全反直觉但非常有洞察力
- 它揭示了一个基本问题：即使提供了丰富的信息，AI系统可能不使用它，如果存在"更简单"的替代方案
- 这反映了人类认知偏见：我们倾向于使用最不费力的推理路径
- 对Spatial AGI的启示：仅仅向系统提供空间信息是不够的；我们必须设计架构和训练策略，确保系统实际使用它

**掩蔽作为主动学习机制**：
- Geometry-Unleashing Masking不仅仅是一种技术技巧；它是一种主动学习哲学
- 通过移除"容易的答案"（2D外观捷径），系统被迫学习"更难的答案"（几何推理）
- 这与教育学中的主动学习概念相关联：通过挑战学生，他们学到更多
- 对Spatial AGI的启示：训练应该有意识地设计挑战，迫使系统学习我们真正想要的能力

### 最意外的结果

**动态场景中几何注入的负面影响**：
- 图1显示，在朴素融合下，添加几何分支可能在动态视频中降低性能
- 这完全出乎意料：几何信息理论上应该有帮助，而非有害
- 但它揭示了：如果几何线索与外观线索不一致或融合不当，几何信息可能成为噪声
- 对Spatial AGI的启示：多模态融合需要仔细设计；简单地添加更多信息并不总是更好

**动态场景中的收益更大**：
- 消融研究显示，GeoSR的改进在动态基准上更为明显
- 这也有些意外，因为动态场景似乎更复杂，改进可能更难
- 但这反映了：动态场景中外观线索更不稳定，几何线索的价值更加突出
- 对Spatial AGI的启示：系统需要在动态环境中特别强调几何推理

### 最有价值的启发

**从信息注入到信息利用**：
- 论文从"如何注入几何信息"转向"如何确保几何信息被利用"
- 这是一个重要的范式转变：从关注表示到关注推理过程
- 对Spatial AGI的启示：系统的空间智能不仅取决于它知道什么，还取决于它如何使用它

**强制 vs. 适应性**：
- Geometry-Unleashing Masking强制使用几何（"鞭策"）
- Geometry-Guided Fusion适应性地使用几何（"引导"）
- 两种机制互补：确保几何被使用，但以合理方式
- 对Spatial AGI的启示：需要强制与适应性的平衡来培养鲁棒的空间智能

**细粒度控制的必要性**：
- token级别的门控允许在不同空间位置有不同程度的几何依赖
- 这比全局决策（整个图像用或不用几何）更灵活
- 对Spatial AGI的启示：空间推理需要细粒度的、局部的决策，而不是粗糙的、全局的启发式

### Q3的思考过程

**我选择的第三个核心问题**：基于Q1和Q2，这篇文章的核心创新点和主要局限性是什么？

**为什么问这个问题**：

1. **从理解到评估**：
   - Q1帮助我理解"是什么"：核心算法原理
   - Q2帮助我理解"为什么和如何"：与Spatial AGI的关系
   - Q3帮助我评估"多好"：创新点和局限性
   - 这种从理解到评估的递进对于全面分析至关重要

2. **批判性思维**：
   - 通过询问创新点，我被迫思考什么真正新颖 vs. 什么是增量改进
   - 通过询问局限性，我被迫思考什么仍然缺失，什么可能被夸大
   - 这种批判性视角对于科学评估至关重要

3. **实践相关性**：
   - 了解局限性帮助判断技术是否准备好实际部署
   - 了解创新点帮助判断它是否值得进一步研究或采用
   - 这种实践相关性对Spatial AGI特别重要，因为我们关心实际部署

**核心创新点**：
1. **发现了几何利用不足的问题**：这是一个重要的观察，但不是技术贡献
2. **Geometry-Unleashing Masking**：简单但有效的方法，训练期间强制几何使用
3. **Geometry-Guided Fusion**：细粒度的门控机制，适应性路由几何信息
4. **在静态和动态场景中的一致有效性**：展示了方法的广泛适用性

**主要局限性**：
1. **仍依赖预训练3D模型**：几何token的质量完全取决于预训练的3D基础模型，如果这些模型有偏差或局限，GeoSR无法补偿
2. **掩蔽在推理时禁用**：掩蔽仅用于训练，推理时系统可能回到旧习惯；可能需要持续的正则化
3. **数据质量限制**：当前空间推理基准的构建可能包含歧义，如论文附录所示（图6和图7）
4. **计算成本**：虽然论文声称开销小，但3D模型的推理仍然比纯2D方法更昂贵
5. **显式3D表示的缺失**：虽然从单眼视频提取隐式几何，但这可能不如显式3D表示精确

**对Spatial AGI的启示**：
- GeoSR是一个重要步骤，但不是最终解决方案
- 空间智能需要更深层次的整合：几何推理、语义理解、动态建模、交互学习的结合
- 未来的Spatial AGI系统可能需要超越当前的VLM+几何分支范式

## 总结

### 核心发现总结

1. **几何利用不足问题**：
   - 视觉语言模型即使提供了几何token，仍倾向于依赖2D外观捷径
   - 在朴素融合下，几何信息可能被忽略甚至损害性能
   - 这是论文观察到的反直觉但可复现的现象

2. **GeoSR解决方案**：
   - Geometry-Unleashing Masking: 训练期间掩蔽视觉token，强制几何使用
   - Geometry-Guided Fusion: 细粒度门控机制，自适应路由几何信息
   - 两种机制协同工作，使几何token成为可行动证据

3. **广泛有效性**：
   - 在静态和动态空间推理基准上均优于先前方法
   - 动态场景中的改进更显著（DSR-Bench: 88.0 vs. GPT-4o: 18.8）
   - 计算开销可忽略，适合实际部署

### 对Spatial AGI的意义

1. **范式转变**：
   - 从"如何注入几何信息"到"如何确保几何信息被利用"
   - 从关注表示到关注推理过程
   - 从被动信息提供到主动信息使用

2. **关键技术洞察**：
   - 掩蔽作为约束机制迫使多模态系统的主动学习
   - 门控融合作为细粒度路由机制实现适应性推理
   - 问题感知检索提取相关信息而非全局聚合

3. **实用价值**：
   - 单眼视频提取几何，减少对显式3D传感器的依赖
   - 计算效率高，适合实时应用
   - 鲁棒到静态和动态场景，具有广泛适用性

4. **未来方向**：
   - 需要更深层次的多模态整合
   - 需要更复杂的空间推理能力（多步、交互式、学习式）
   - 需要解决数据质量问题和基准歧义

## 技术细节补充

### 注意力机制在TopK掩蔽中的作用

在动态场景的TopK掩蔽中，使用QFormer的交叉注意力权重来确定哪些几何token对回答问题最相关：

1. **注意力张量**：
   A ∈ [0,1]^{h×L_B×(H_G W_G T)}
   - h是注意力头数
   - L_B是瓶颈token长度
   - H_G W_G T是几何token的时空分辨率

2. **平均注意力计算**：
   u_j = 1/(h L_B) ∑_{k=1}^h ∑_{i=1}^{L_B} A_{k,i,j}
   - 计算每个几何token在所有头和瓶颈token上的平均注意力概率
   - 作为相关性度量

3. **归一化**：
   s_j = (u_j - min(u)) / (max(u) - min(u) + ε)
   - 归一化到[0,1]范围
   - ε确保数值稳定性

4. **TopK选择**：
   M = TopK(s, K)
   - 选择分数最高的K个token位置
   - 在视觉token的对应位置应用掩蔽

### 门控机制的初始化和训练

门控α通过sigmoid函数从线性变换获得：

α = σ(W_g [V‖G] + b_g)

**初始化**：
- W_g: 通常随机初始化或从Xavier初始化
- b_g: 通常初始化为0，让门控最初平衡

**训练动态**：
- 在训练开始时，门控可能接近0.5（平衡融合）
- 随着训练进行，门控学习在哪些位置几何更可靠
- Geometry-Unleashing Masking确保几何被学习为可靠

**推理行为**：
- 在几何提供独特信息的区域，门控偏向几何（α接近0）
- 在外观足够的区域，门控偏向视觉（α接近1）
- 这是适应性、细粒度的信息融合

### 层归一化（LN）的作用

在门控计算中使用Layer Normalization：

V = LN_v(F~V)
G = LN_g(F~G)

**作用**：
1. **稳定训练**：
   - 归一化每个token的特征
   - 减少内部协变量偏移
   - 加速收敛

2. **尺度对齐**：
   - 确保视觉和几何特征在相似尺度
   - 使门控决策不受特征尺度影响

3. **训练稳定性**：
   - 防止梯度爆炸或消失
   - 特别是对于深度网络和复杂融合架构

## 评估指标解释

### 数值问题平均相对准确率

在VSI-Bench中，数值问题（对象计数、距离、大小等）使用平均相对准确率而非严格准确率：

1. **相对误差容忍**：
   - 小错误: 0-10%误差仍可能部分正确
   - 中等错误: 10-30%误差部分正确
   - 大误差: >30%误差不正确

2. **计算方式**：
   - 对不同相对误差容忍度计算准确率
   - 取平均得到总体指标
   - 允许部分正确答案获得部分分数

3. **为什么使用相对准确率**：
   - 空间测量本质上是估计的
   - 严格准确率过于严厉
   - 相对准确率更好地反映实用性

### 多选题准确率

标准准确率：预测答案 = 基准答案

### 子任务平衡

VSI-Bench和DSR-Bench都包含多个子任务类型：
- 确保评估全面的空间推理能力
- 避免模型过度优化到特定任务
- 平均分数反映整体能力

- 在动态推理中显著超越（88.0 vs. GPT-5: 21.1）
- 表明专门化的空间推理方法可以超越通用模型

### 通用视频模型

**优势**：
- 开源，可微调
- 强大的视觉理解能力

**劣势**：
- 未专门针对空间推理优化
- 可能过度依赖外观线索

**性能**：
- Qwen2.5-VL-7B: 静态40.9，动态18.8
- LLaVA-Video-7B: 静态48.5，动态22.3
- InternVL3-78B: 静态71.2，动态25.8

**GeoSR的优势**：
- 在静态推理上竞争（68.3 vs. InternVL3-78B: 71.2）
- 考虑到GeoSR使用7B模型，性能优异
- 在动态推理上大幅超越（88.0 vs. 最佳25.8）

### 空间推理模型

**VG-LLM**：
- 方法：提取VGGT几何token，token级融合
- 性能：静态67.9，动态55.2
- 限制：朴素融合，几何可能未充分利用

**Spatial-MLLM**：
- 方法：空间分支 + 空间感知帧采样
- 性能：静态65.3
- 限制：仅静态推理，动态场景不适用

**VLM-3R**：
- 方法：指令对齐的3D重建先验
- 性能：动态28.2
- 限制：需要显式SfM式重建，可扩展性受限

**GSM**：
- 方法：检索动态几何证据，附加到视觉token
- 性能：动态87.0
- 优势：在动态推理上表现优异
- 限制：几何注入收益可能有限（如论文所示）

**GeoSR vs. GSM**：
- 动态：88.0 vs. 87.0（略优）
- 但GeoSR是更通用的框架（静态+动态）
- GSM需要动态几何先验，GeoSR可以使用不同3D模型

## 结论

本文通过GeoSR框架提出了解决VLMs空间推理局限性的新颖方法。核心洞察是，仅仅向VLMs注入几何token并不确保它们被有效利用。通过Geometry-Unleashing Masking和Geometry-Guided Fusion，GeoSR确保几何线索成为空间推理的可行动证据。

实验在静态和动态空间推理基准上验证了有效性，显示对先前方法的一致改进，特别是在动态场景中。计算开销可忽略，使方法适合实际部署。

对Spatial AGI的主要贡献：
- 揭示了几何利用不足的问题
- 提供了强制和适应性几何使用的框架
- 展示了从信息表示到信息利用的范式转变
- 为未来的空间智能系统提供了重要的技术基础

未来工作应该关注：更好的数据集、持续学习机制、扩展到其他模态、端到端训练、复杂推理能力。这些方向将进一步推动Spatial AGI的发展。
