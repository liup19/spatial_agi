## 核心信息

### 摘要
光通过湍流场在飞机周围传播会导致光学失真，通常称为航空光学效应（aero-optic effects）。开发减轻这些效应的方法需要大量现实的航空光学数据。然而，获取这种数据的方法，包括实验、计算流体动力学和简单的相位屏算法（例如，沸腾流），每个都有显著的缺点，如高成本、高计算、数量有限和/或统计不准确。最近，已经提出了数据驱动的方法，这些方法在计算上高效并且可以合成航空光学数据以匹配测量数据的统计特性，但这些方法仍然有缺点，包括质量有限、统计不准确和使用复杂算法。在本文中，我们介绍了 ReVAR（Re-whitened Vector AutoRegression），一种用于生成合成航空光学数据以匹配测量数据统计特性的数据驱动算法。该算法中的一个关键贡献是 Long-Range AutoRegression，一种结合了标准自回归与一组低通滤波器以适应数据短程和长程时间统计的线性预测模型。ReVAR 使用 Long-Range AR 以及空间重新白化步骤将测量的航空光学数据转换为在时间和空间上不相关的白噪声。ReVAR 可以通过反转此过程使用白噪声输入生成合成航空光学数据。使用两个测量的湍流边界层数据集，我们演示了 ReVAR 比两种常规相位屏生成方法以及现有的单时间滞后自回归模型更好地匹配测量数据的短程和长程时间功率谱以及其他关键指标。

### 关键贡献
1. **ReVAR 算法**: 一种数据驱动的算法，用于生成合成航空光学数据以匹配测量数据的统计特性
2. **Long-Range AR**: 结合标准自回归与低通滤波器的线性预测模型，适应数据短程和长程时间统计
3. **空间重新白化**: 将测量的航空光学数据转换为在时间和空间上不相关的白噪声的步骤
4. **合成数据生成**: 通过反转过程使用白噪声输入生成合成航空光学数据

## 核心技术

### ReVAR 算法架构

**核心思想**:
使用数据驱动的方法生成航空光学数据，通过 Long-Range AutoRegression 和空间重新白化，将测量数据转换为白噪声，然后反转过程生成合成数据。

**技术组件**:

**1. Long-Range AutoRegression**:
```
功能：适应数据短程和长程时间统计

实现：
- 标准自回归 + 低通滤波器
- 线性预测模型
- 同时拟合短程和长程时间统计

优势：
- 捕获短程和长程依赖
- 计算高效
- 统计准确性高
```

**2. 空间重新白化（Spatial Re-whitening）**:
```
功能：将测量的航空光学数据转换为在时间和空间上不相关的白噪声

实现：
- 空间重新白化步骤
- 将测量数据转换为白噪声
- 时间和空间解相关

优势：
- 简化合成过程
- 保持统计特性
- 便于数据生成
```

**3. 合成数据生成**:
```
功能：通过反转过程使用白噪声输入生成合成航空光学数据

实现：
- 使用白噪声输入
- 反转 Long-Range AR
- 反转空间重新白化

优势：
- 生成与测量数据统计匹配的合成数据
- 计算高效
- 质量高
```

## 总结

ReVAR 是一种数据驱动的算法，用于生成合成航空光学数据以匹配测量数据的统计特性。ReVAR 使用 Long-Range AutoRegression 结合标准自回归与低通滤波器，以及空间重新白化步骤，将测量的航空光学数据转换为在时间和空间上不相关的白噪声。然后通过反转这个过程，使用白噪声输入生成合成航空光学数据。实验表明，ReVAR 比两种常规相位屏生成方法以及现有的单时间滞后自回归模型更好地匹配测量数据的短程和长程时间功率谱以及其他关键指标。

3. 空间重新白化：将测量数据转换为白噪声的步骤
4. 合成数据生成：通过反转过程生成合成航空光学数据
