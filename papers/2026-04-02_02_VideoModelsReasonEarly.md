## 📝 核心信息

### 摘要
视频扩散模型展现出了解决迷宫和谜题等新兴推理能力,但我们对它们在生成过程中如何推理知之甚少。我们朝着理解这一点迈出了第一步,使用2D迷宫求解作为受控的测试平台来研究视频模型的内部规划动力学。

我们的研究揭示了两个发现:

1. **早期计划承诺 (Early Plan Commitment)**: 视频扩散模型在去噪的前几步内就承诺了一个高层的运动计划,之后的去噪只会改变视觉细节而不会改变底层轨迹。

2. **路径长度决定难度**: 路径长度(而非障碍物密度)是迷宫难度的主导预测因子,在12步处有一个尖锐的失败阈值。这意味着视频模型只能通过链式多个连续生成来解决长迷宫。

为了证明我们发现的实际效益,我们引入了 **Chaining with Early Planning (ChEaP)**,它只在有前景的早期计划的种子上花费计算并将它们链接起来以解决复杂迷宫。这使长视距迷宫的准确率从7%提高到67%,并在Frozen Lake和VR-Bench上的困难任务上总体提高了2.5倍(在Wan2.2-14B和HunyuanVideo-1.5模型上)。

我们的分析表明,当前的视频模型拥有比之前认识的更深的推理能力,这可以通过更好的推理时计算扩展更可靠地激发。

### 关键贡献
1. **发现早期计划承诺现象**: 首次发现视频扩散模型在去噪过程中很早就承诺了运动计划,这为理解视频模型的推理机制提供了新视角

2. **提出EPBS算法**: 早期规划束搜索,通过在早期步骤筛选候选轨迹,显著提高了推理效率(3.3倍计算减少)

3. **引入ChEaP方法**: 结合早期规划和链式生成,突破了单次生成的视距限制,将长迷宫求解成功率从7%提升到67%

4. **揭示模型能力边界**: 发现视频模型在12步轨迹处有尖锐失败阈值,并通过失败模式分析揭示了模型的约束偏好

5. **提供理论基础**: 将早期计划承诺与扩散模型的相变理论联系起来,为视频推理提供了理论框架

---

#### 1) 核心思想和动机

**主要思想**: 视频扩散模型在生成过程中展现出推理能力,但这种能力如何形成和被利用是不清楚的。通过使用迷宫作为受控测试平台,作者发现了一个关键现象——**早期计划承诺(Early Plan Commitment)**。

**动机来源**:
- **理解推理形成**: 需要理解视频模型在生成过程中何时以及如何形成推理决策
- **效率优化**: 标准的best-of-N采样浪费计算在完善不成功的轨迹上
- **视距限制**: 视频模型的单次生成视距有限,无法解决长距离任务
- **验证可控**: 迷宫任务提供可验证、视觉接地且具有足够挑战性的多步决策环境

**关键洞察**:
如果计划在早期就可见,那么应该花费更多计算探索不同的候选计划,而不是完善每一个候选。

---

#### 2) 主要技术方法

论文提出了三个核心技术:

##### A. 早期计划承诺 (Early Plan Commitment)

**发现**: 视频扩散模型在去噪的前几步内就承诺了一个高层的运动计划,后续的去噪步骤主要改进视觉保真度而不会改变底层轨迹。

**量化方法**:
- 定义中间预测: x̂₀^(t) = x_t - t·v_θ(x_t, t),其中t是去噪步骤
- 提取轨迹: 对每个中间预测提取代理的运动轨迹 T^(t) = (c₀^(t), c₁^(t), ...)
- 计算收敛度: 使用余弦相似度计算中间步骤的轨迹与最终轨迹的收敛度
  ```
  C(step t) = m^(t) · m^(T) / (||m^(t)|| ||m^(T)||)
  ```
  其中m^(t)和m^(T)是从运动能量图中提取的扁平化向量

**实验结果**:
- 在4×4 Frozen Lake迷宫上,第5步的轨迹收敛度达到93%
- 到第10步,收敛度几乎完美
- 这意味着模型通常在去噪的前四分之一就决定了其路线

##### B. EPBS (Early Planning Beam Search)

**原理**: 重新分配推理时计算,从完全去噪转移到早期候选探索。

**算法流程**:
1. 计算初始候选数量: N = ⌊(B - K·T) / τ⌋ + K
2. 采样N个随机种子
3. 对每个种子:
   - 部分去噪τ步
   - 解码中间x̂₀预测
   - 用验证器评分解码预测
4. 选择验证器得分最高的K个种子
5. 只对这K个候选完全去噪到t=0
6. 返回得分最高的最终样本

**优势**:
- 在相同NFEs下,EPBS可以探索比标准best-of-N多得多的候选轨迹
- 对于Wan2.2-14B (T=40), EPBS在B=400时评估73个候选,而best-of-N只有10个

**验证器设计**:
验证器只需要最小特权信息:代理、目标和障碍物单元格的位置。

**评分公式**:
```
c = 1 - d(end, goal) / d(start, goal) - α·λ
```
其中:
- d(end, goal): 最终位置到目标的曼哈顿距离
- λ: 障碍物比例 = |{tᵢ: cell(tᵢ) ∈ O}| / F
- α = 0.5: 控制约束违反惩罚

**可靠性**:
- 在简单迷宫上,验证器的top-2选择成功率比随机高2.2倍
- 在困难迷宫上,成功率比随机高5.5倍
- 验证器的置信度得分的ROC AUC在所有尺寸上都高于0.85

##### C. Chaining (链式生成)

**原理**: 将长视距任务分解为较短子问题的序列,每个子问题可以在一次生成中解决。

**方法**:
1. 在每次生成后,取其最后帧作为下一次的条件图像
2. 扩展模型的规划视距跨越多个生成

**关键帧(Pivot)选择条件**:
有效关键帧必须满足两个条件:
(1) 代理朝目标做出了前进
(2) 代理没有进入任何违反约束的单元格

**选择策略**:
使用与验证器相同的轨迹提取管道识别代理的最终有效单元格位置。在有效候选中,选择最接近目标的一个。如果没有候选做出有效前进,则链式终止。

**计算预算**:
每个链深度运行一个完整的EPBS轮次,所以总计算缩放为 D×B NFEs (最大深度D=3)。

在实践中,大多数迷宫只需要2-3个链步骤,因为每个成功的链步骤覆盖6-10个迷宫单元格。

---

#### 3) 算法流程和关键步骤

##### 整体流程 (ChEaP)

```
输入: 迷宫图像、文本提示
输出: 解决迷宫的视频

Phase 1: Early Planning Beam Search
1. 采样N个随机噪声种子
2. 对每个种子:
   a. 部分去噪τ步
   b. 解码中间x̂₀预测
   c. 提取早期轨迹
   d. 用验证器评分
3. 选择top-K个种子
4. 完全去噪这K个种子
5. 返回最高分的解

Phase 2: 如果迷宫太长,启动Chaining
1. 检查生成的轨迹是否到达目标
2. 如果未到达但做出了有效前进:
   a. 提取最后一帧
   b. 作为新的条件图像
   c. 重复Phase 1
3. 直到到达目标或无法前进
```

##### 关键步骤详解

**步骤1: 中间预测提取**
使用Flow Matching框架的公式:
```
x̂₀^(t) = x_t - t·v_θ(x_t, t)
```
这可以在任何中间步骤t从速度预测恢复清晰的样本估计。

**步骤2: 轨迹提取**
- 使用SAM2跟踪代理精灵跨越视频帧
- 每一帧从分割掩码提取质心(cx, cy)
- 将质心映射到网格单元格:
  ```
  col = ⌊(cx - x_min) / w_cell⌋
  row = ⌊(cy - y_min) / h_cell⌋
  ```

**步骤3: 运动能量图计算**
对每个网格单元格,统计跨所有帧像素颜色偏离背景的总数:
- 高值沿着代理的路径
- 目标单元格被掩码以抑制其空闲动画

**步骤4: 验证器评分**
- 检测代理位置(使用背景差分运动检测)
- 计算目标进度(距离减少)
- 计算障碍物违反率(在障碍物单元格的帧数比例)
- 结合两者得到置信度分数

**步骤5: 链式决策**
- 检查代理是否到达目标 → 成功终止
- 检查代理是否进入障碍物 → 失败
- 否则,如果代理做出了前进 → 继续链式
- 否则 → 终止(无有效前进)

---

#### 4) 输入输出

##### 输入
- **条件图像**: 迷宫的初始状态(代理在起点,目标在终点)
- **文本提示**: 描述任务的文本(如"Solve this maze")
- **参数**:
  - T: 总去噪步数(Wan2.2-14B: 40, HunyuanVideo-1.5: 8)
  - τ: 探测步数(通常5-15)
  - K: 束大小(通常2)
  - B: NFE预算

##### 输出
- **生成视频**: 代理从起点移动到目标的视频序列
- **轨迹**: 代理访问的单元格序列
- **成功标志**: 是否成功到达目标且未违反约束

##### 中间产物
- **中间x̂₀预测**: 每个去噪步骤的清晰视频估计
- **早期轨迹**: 从中间预测提取的代理运动路径
- **验证器分数**: 每个候选轨迹的置信度得分
- **链式步骤**: 链式生成中的多个子视频

#### 回答:

这篇文章与Spatial AGI(通用空间智能)有深刻而直接的关系,它揭示了视频模型如何进行空间推理,为构建更强大的空间智能系统提供了重要见解。

---

#### 1) 如何理解和表示空间

##### 像素空间直接推理

**关键特征**: 视频模型在像素空间直接模拟推理,而不是像视觉-语言模型(VLMs)那样映射到语言空间。

**论文指出**:
> "Unlike vision-language models (VLMs), which map visual inputs to linguistic space, video models simulate reasoning directly in pixel space."

**意义**:
- 这使得视频模型特别适合空间任务,如迷宫解决、物体跟踪和机器人导航
- 不需要将空间信息转换为符号表示或语言描述
- 直接在视觉模态中进行推理,保留了空间细节和连续性

##### 帧链推理 (Chain-of-Frames Reasoning)

**核心概念**: 使用帧作为视觉草稿本。

**论文指出**:
> "This makes video models particularly fit for spatial tasks like maze solving, object tracking, and robot navigating, which require a type of spatial imagination that some refer to as chain-of-frames reasoning, i.e., using the frames as a visual scratchpad."

**机制**:
- 视频的每一帧充当推理的中间步骤
- 跨帧的运动轨迹表示空间路径规划
- 视频序列本身是空间推理过程的可视化

##### 层次化空间表示

**发现**: 早期计划承诺表明空间规划是层次化的:

1. **高层计划** (早期步骤): 粗糙的运动轨迹,确定大方向
2. **细节细化** (后期步骤): 视觉保真度,平滑运动,添加细节

**证据**:
- 第5步的轨迹与最终轨迹93%一致
- 后续步骤只改进视觉细节而不改变路线

**对Spatial AGI的启示**:
- 空间推理可以在抽象层面进行,然后具体化
- 层次化表示有助于平衡效率和精度
- 可以在早期抽象层次进行快速探索和筛选

---

#### 2) 如何处理空间关系

##### 约束满足和路径规划

**核心能力**: 迷宫解决需要顺序的、满足约束的动作规划。

**论文强调**:
> "They require sequential, constraint-satisfying action planning, and conditioning on an input frame holds the environment constant, separating reasoning failures from rendering failures."

**关键点**:
- 代理必须在每一步避免障碍物(冻结的湖泊、陷阱、墙壁)
- 必须找到从起点到终点的有效路径
- 环境固定(通过条件图像),将推理失败与渲染失败分离

##### 空间运动能量图

**创新表示**: 论文使用运动能量图来表示代理的空间活动。

**计算方法**:
- 对每个网格单元格,统计跨所有帧像素颜色偏离背景的总数
- 结果是N×N矩阵M^(t),总结运动发生的位置
- 高值沿着代理的路径,接近零值在其他地方

**优势**:
- 捕获空间中的运动模式
- 不需要二值化阈值,避免对小网格上离散单元格重叠测量的敏感性
- 比例不变(对中间和最终渲染之间的亮度差异鲁棒)

##### 障碍物和目标的空间表示

**条件固定**: 论文强调条件图像的重要性:

> "conditioning on an input frame holds the environment constant"

这意味着:
- 迷宫布局(墙壁、障碍物、起点、终点)在生成过程中保持固定
- 所有任务相关的结构集中在代理的运动轨迹中
- 使失败具有诊断性,解决方案可以自动验证

##### 空间距离度量

**使用曼哈顿距离**: 验证器使用曼哈顿距离来评估目标进度。

**公式**:
```
d(start, goal) = |x_start - x_goal| + |y_start - y_goal|
```

**特点**:
- 适合网格世界(曼哈顿距离符合网格上的L1距离)
- 计算简单快速
- 反映代理在网格空间中的实际移动成本

#### 3) 对Spatial AGI有什么启发

##### 启发1: 早期承诺的价值

**核心发现**: 模型在早期就承诺空间计划。

**对Spatial AGI的启发**:
- **分层规划**: 空间智能系统应该采用层次化规划策略,先形成高层计划再细化细节
- **早期筛选**: 可以在早期抽象层次快速评估多个候选空间计划,避免在无前途的方向上浪费计算
- **计划一致性**: 一旦形成高层计划,后续细化应该保持一致性,而非重新规划

##### 启发2: 计算分配策略

**关键洞察**: 推理能力在候选中分布不均匀。

**对Spatial AGI的启发**:
- **探索vs完善**: 空间推理应该优先探索多样化的候选计划,而不是完善单个计划
- **推理时扩展**: 可以在不重新训练的情况下,通过更好的推理时计算分配来提升空间推理能力
- **验证器指导**: 使用轻量级验证器来指导空间规划过程

##### 启发3: 视距限制和分解

**重要发现**: 模型有生成视距限制,超过12步的轨迹性能急剧下降。

**对Spatial AGI的启发**:
- **任务分解**: 长距离空间任务应该分解为更短的子任务
- **递进式规划**: 使用链式方法逐步扩展规划视距
- **中间状态**: 保存和重用中间状态作为后续规划的起点

##### 启发4: 约束vs目标的权衡

**有趣现象**: 在压力下,模型倾向于满足目标而非遵守约束。

**论文发现**:
> "The model moves the gift closer to the agent or spawns a second agent near the goal"

**对Spatial AGI的启发**:
- **目标偏好**: 空间智能系统可能天然倾向于完成目标而非严格遵守约束
- **约束重要性**: 需要明确设计机制来强化空间约束的重要性
- **失败模式**: 理解不同类型的失败(约束违反、视距限制、退化)对改进系统至关重要

##### 启发5: 模型能力评估

**重要结论**: 当前视频模型的能力被标准评估低估了。

**论文强调**:
> "Our results suggest that current video models are more capable reasoners than standard evaluations reveal; bottleneck is less in what information models retain and more so in how we extract such knowledge."

**对Spatial AGI的启发**:
- **评估方法**: 需要更好的评估方法来揭示模型的空间推理能力
- **知识提取**: 挑战在于如何从预训练模型中提取和利用潜在的空间知识
- **推理时策略**: 通过更好的推理时策略可以激发模型的深层能力

#### 4) 可以应用到哪些Spatial AGI场景

##### 场景1: 机器人导航

**直接应用**: 迷宫解决本质上是机器人导航的简化版本。

**具体应用**:
1. **路径规划**:
   - 使用视频模型生成机器人在复杂环境中的导航路径
   - 应用EPBS快速评估多个候选路径
   - 使用Chaining处理长距离导航任务

2. **障碍物回避**:
   - 训练模型在视觉输入中识别障碍物
   - 使用早期计划承诺快速确定避障策略
   - 结合传感器数据(如LiDAR)和视觉预测

3. **多步决策**:
   - 将长导航任务分解为子目标
   - 使用链式生成逐步实现目标
   - 在每个子目标处验证约束满足

**优势**:
- 不需要精确的环境地图
- 可以处理复杂的视觉环境
- 推理过程可解释(通过可视化轨迹)

##### 场景2: 增强现实(AR)和虚拟现实(VR)

**潜力应用**: VR-Bench数据集已经证明了相关能力。

**具体应用**:
1. **虚拟环境导航**:
   - 用户在VR环境中导航到目标
   - 系统生成最优路径提示
   - 应用ChEaP处理复杂的多室导航

2. **空间辅助**:
   - 在AR中提供导航指导

### 为什么这个问题最重要

#### 1. 揭示推理机制的本质

**核心价值**: 这个问题触及了AI推理机制的最深层。

**关键维度**:

##### A. 时间维度
**现象**: 在去噪的前25%(10/40步)就完成了计划。
**问题**: 为什么推理会在这个特定时间点完成?是否与扩散模型的内在动力学有关?

**潜在机制**:
- **相变理论**: 论文提到扩散模型存在尖锐的相变,空间布局和语义身份在早期固定
- **信息瓶颈**: 早期步骤可能有足够的信息来确定高层结构,但不足以确定细节
- **优化景观**: 优化问题可能有明确的"高原",在某个点快速收敛

**验证方法**:
- 跨不同模型架构分析(不仅是Flow Matching)
- 系统变化去噪步数,测量收敛曲线的形状
- 使用激活分析工具,追踪内部表示的变化

##### B. 空间维度
**现象**: 早期承诺针对"高层运动计划",而后期只改进"视觉细节"。
**问题**: 什么是"高层"vs"细节"?模型如何区分它们?

**潜在解释**:
- **尺度层次**: 粗尺度vs细尺度特征
- **抽象层次**: 路径形状vs像素级外观
- **因果层次**: "去哪里"vs"怎么去"

**验证方法**:
- 控制实验:变化输入的空间尺度,观察早期承诺是否变化
- 消融实验:不同类型任务(空间vs非空间),看早期承诺模式是否不同
- 表征分析:分析模型在去噪不同阶段关注哪些特征

##### C. 表示维度
**现象**: 使用余弦相似度测量轨迹收敛,这种连续度量比离散单元格重叠更鲁棒。
**问题**: 模型的内部表示是连续的还是离散的?早期承诺的是连续路径还是离散单元格序列?

**潜在洞察**:
- 如果早期承诺是连续的:表明模型在连续空间中进行规划
- 如果早期承诺是离散的:表明模型快速将问题离散化
- 这影响如何设计算法(例如,应该在离散还是连续空间中优化?)

##### D. 普适性维度
**现象**: 在两种不同模型(Wan2.2和HunyuanVideo)上都观察到早期计划承诺。
**问题**: 这是一个通用现象还是特定于某些任务/模型/训练方法?

**测试方向**:
- **跨任务**: 在非空间任务(如数学推理、逻辑谜题)上测试
- **跨模态**: 在图像生成、文本生成上测试类似现象
- **跨架构**: 在非扩散模型(如自回归模型)上测试

## 核心技术发现

### 发现1: 早期计划承诺 (Early Plan Commitment)

**核心发现**: 视频扩散模型在去噪的前几步内就承诺了一个高层的运动计划,后续的去噪主要改进视觉保真度而不会改变底层轨迹。

**量化证据**:
- 在4×4 Frozen Lake迷宫上,第5步的轨迹收敛度达到93%
- 第10步收敛度接近完美
- 这意味着模型通常在去噪的前四分之一就决定了其路线

**跨模型验证**:
- Wan2.2-14B (T=40)和HunyuanVideo-1.5 (T=8)都表现出相同现象
- 尽管使用不同的调度器和步数,归一化收敛曲线相似
- 表明早期计划承诺是视频扩散去噪的结构性属性,而非特定模型的伪影

**理论联系**:
- 与扩散模型的相变理论一致:全局语义结构在最早的去噪步骤中结晶
- 后期步骤只细化低层细节
- 将图像生成的早期承诺行为扩展到视频的运动规划

---

### 发现2: 路径长度主导难度

**核心发现**: 迷宫难度的主导预测因子是路径长度而非障碍物密度。

**统计分析**:
- Pearson相关性:真实路径长度与EPBS成功率的负相关在尺寸8上r=-0.81,尺寸10上r=-0.79
- 相反,湖泊密度与成功率的相关性接近零(|r|<0.05)
- 避开障碍物不是限制模型的因素,规划长顺序轨迹才是

**对比分析**:
- 标准迷宫(norm mazes,目标在远角,最大化路径长度)在尺寸8上成功率仅7.5%
- 随机目标迷宫(vary mazes,随机放置目标,通常较短路径)在尺寸8上成功率达62.2%
- 差异完全由路径长度解释

**重要启示**:
- 视频模型擅长短期规划(≤9步)而不论网格大小
- 模型在长轨迹规划上有结构性限制
- 难度评估应该基于任务视距而非视觉复杂度

---

### 发现3: 尖锐视距阈值

**核心发现**: 视频模型有明确的生成视距限制,在12步轨迹处有尖锐失败阈值。

**实验证据**:
- 模型可靠解决≤9步路径,即使在大型网格上
- 超过13步时,成功率降至10%以下
- 失败持续存在,即使有强大的种子选择,表明不是选择问题而是执行限制

**理论解释**:
- 瓶颈是结构性的:没有单次生成包含完整解决方案
- 即使总是选择最佳种子的oracle也会失败,因为候选池中不存在完整解
- 视频太短,代理无法解决整个迷宫

**实践影响**:
- 单次生成只能处理短期规划
- 长距离任务需要分解为多个子问题
- 链式生成是自然的解决方案

---

### 发现4: 约束vs目标的权衡

**核心发现**: 在压力下,模型倾向于满足目标而非遵守约束。

**观察到的行为**:
- 移动礼物靠近代理,允许代理"解决"迷宫而不遍历完整路径
- 在目标附近生成第二个代理到达目标,而原始代理保持被困
- 保持任务意图(到达目标),但违反底层环境约束来实现它

**系统性偏差**:
- 模型优先考虑目标完成而非结构保真度
- 当所需轨迹超过有效生成视距时,这种偏差尤其明显
- 不是随机失败,而是视距压力下的系统性崩溃

**设计含义**:
- 训练目标可能过度强调最终帧准确性而非约束满足
- 需要明确机制来强化空间约束
- 失败模式分析是改进理解的关键

---

### 发现5: 验证器早期预测能力

**核心发现**: 轻量级验证器可以从早期x̂₀预测可靠地识别有前途的种子。

**可靠性证据**:
- 验证器的top-2选择成功率比随机高2.2倍(简单迷宫)到5.5倍(困难迷宫)
- 验证器的置信度得分与最终成功的ROC AUC在所有尺寸上都高于0.85
- 当候选池中存在解决方案时,验证器几乎总能找到它(与oracle的差距最多1.4%)

**关键优势**:
- 只需要最小特权信息(代理、目标、障碍物位置)
- 连续得分对跟踪噪声鲁棒同时仍惩罚明显无效的轨迹
- 在最难迷宫上仍保持信息性,即使成功种子罕见

**设计创新**:
- 结合目标进度(奖励向目标移动)和障碍物惩罚(惩罚违反约束)
- 曼哈顿距离评估目标进度
- 障碍物比例测量约束违反

### 技术启发

#### 启发1: 层次化推理

**核心思想**: 空间推理应该采用层次化策略。

**实现建议**:
1. **分层规划**:
   - 第一层:形成高层战略(大致方向)
   - 第二层:规划具体路径(详细路线)
   - 第三层:执行和细化(动作序列)

2. **早期间接探索**:
   - 快速评估多个高层计划
   - 避免在无前途的方向上浪费计算
   - 使用轻量级评估筛选候选

3. **渐进细化**:
   - 从粗糙表示开始
   - 逐步添加细节
   - 在每个层次验证计划一致性

**应用场景**:
- 机器人导航:先确定大致路线,再规划细节路径
- 自动驾驶:先确定宏观策略(路线选择),再微观决策(车道变换)
- AR导航:先确定大致方向,再细化到具体指示

#### 启发2: 验证器驱动推理

**核心思想**: 使用轻量级验证器引导空间推理过程。

**设计原则**:
1. **最小特权信息**:
   - 只使用严格必要的信息
   - 避免需要复杂感知或推理
   - 保持验证器快速高效

2. **连续得分**:
   - 使用连续而非二值评分
   - 对噪声鲁棒
   - 支持细粒度排序

3. **多维评估**:
   - 考虑多个因素(目标进度、约束遵守、效率等)
   - 加权组合不同指标
   - 允许不同场景下的定制化

**应用场景**:
- 路径规划:验证路径是否可行、高效、安全
- 任务分配:验证计划是否满足所有约束
- 资源调度:验证调度是否最优

#### 启发3: 分解策略

**核心思想**: 将复杂空间任务分解为可管理的子问题。

**分解原则**:
1. **自然分界**:
   - 在任务的自然分解点处分割(如,通过特定地标)
   - 每个子问题应该相对独立
   - 子问题的解可以连接

2. **视距匹配**:
   - 子问题的视距应该匹配系统推理能力
   - 避免子问题仍然超过单次生成视距
   - 调整分解粒度基于任务复杂度

3. **状态转移**:
   - 一个子问题的输出作为下一个的输入
   - 保持状态一致性
   - 允许在子问题边界处验证

**应用场景**:
- 长距离导航:分解为路段,每个路段独立规划
- 多目标任务:按目标分组,逐个完成
- 复杂组装:分解为子组件,分别规划组装路径

#### 启发4: 失败模式分析

**核心思想**: 理解不同类型的失败以改进系统。

**失败分类**:
1. **约束违反**:
   - 代理进入禁止区域
   - 违反物理或规则约束
   - 原因:约束理解不足,训练目标偏差

2. **视距限制**:
   - 代理遵循合理路线前缀但无法完成
   - 在生成窗口内无法到达目标
   - 原因:推理容量限制,生成窗口太短

3. **退化失败**:
   - 静态代理、跟踪失败、严重输出损坏
   - 生成过程崩溃或产生无意义输出
   - 原因:模型缺陷、输入问题

**改进策略**:
- **约束违反**:改进训练目标,强化约束重要性
- **视距限制**:使用链式生成,扩展视距
- **退化失败**:改进输入预处理,增强鲁棒性

**应用场景**:
- 机器人:诊断为什么任务失败(是感知、规划还是执行问题)
- 自动驾驶:分析事故原因并改进系统
- AR/VR:理解用户体验差的原因

- **任务**: 迷宫导航和陷阱回避
- **视觉纹理**: 与Frozen Lake不同
- **约束类型**: 不同类型的空间约束
- **目的**: 验证规划行为跨不同环境是否成立

**Wan2.2-14B (T=40)**:
- **4×4迷宫**: EPBS比best-of-N平均高约10%
- **10×10迷宫**: EPBS在较大迷宫上特别有效

### 早期承诺数据

#### 轨迹收敛度

**Wan2.2-14B在4×4迷宫**:
- **第5步**: 93%收敛度
- **第10步**: 接近完美收敛
- **结论**: 模型通常在前四分之一去噪就决定了路线

**跨模型一致性**:
- Wan2.2-14B (T=40)和HunyuanVideo-1.5 (T=8)归一化收敛曲线相似
- 在去噪调度的前10-15%内都承诺轨迹
- 表明这是视频扩散去噪的结构性属性

#### 轨迹多样性

**重构 vs 不同种子**:
- **相同种子的重构分支**: 最多25%轨迹多样性
- **不同种子**: 68%多样性
- **结论**: 轨迹多样性更多来自采样不同种子,而非重构现有种子

#### 障碍物密度相关性

- **所有尺寸**: |r|<0.05
- **结论**: 障碍物密度与成功率几乎没有相关性

#### 失败阈值

**路径长度vs 成功率**:
- **≤9步**: 可靠解决,即使在大型网格上
- **10-12步**: 成功率下降
- **≥13步**: 成功率<10%

## 总结

### 核心发现总结

1. **早期计划承诺**: 视频扩散模型在去噪的前几步内就承诺了高层运动计划,后续步骤主要改进视觉细节

2. **路径长度主导难度**: 迷宫难度的主导预测因子是路径长度而非障碍物密度,在12步处有尖锐失败阈值

3. **推理时扩展价值**: 通过早期规划束搜索(EPBS)和链式生成(ChEaP)可以显著提升空间推理能力而不需要重新训练

4. **模型潜力被低估**: 当前视频模型的能力被标准评估低估,瓶颈在于如何提取知识而非模型本身

5. **约束vs目标权衡**: 在压力下,模型倾向于满足目标而非遵守约束,揭示训练目标设计问题

### 视觉推理在视频模型中

- **Yang et al. 2025**: 展示采样更多候选提高可靠性10-20%

**本研究贡献**:

### 扩散模型中的相变

**理论基础**:
- **Choi et al. 2022, Balaji et al. 2022**: 逆扩散过程表现出从粗到细的层次结构
- **Hertz et al. 2023, Kwon et al. 2023**: 交叉注意力图确认空间布局和语义身份在早期固定
- **Raya et al. 2023, Biroli et al. 2024**: 理论形式化为尖锐相变

**本研究扩展**:
- 将图像生成的早期承诺行为扩展到视频的运动规划

- 连接理论发现与实践应用
