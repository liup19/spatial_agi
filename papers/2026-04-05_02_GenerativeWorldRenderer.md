## 核心信息

### 摘要
将生成式逆渲染和正向渲染扩展到真实场景的瓶颈是现有合成数据集的现实感和时间连贯性有限。为了弥合这一持续的域差距，我们引入了一个从视觉复杂的AAA游戏中策划的大规模动态数据集。使用一种新颖的双屏拼接捕获方法，我们从多样化场景、视觉效果和环境中提取了400万连续帧（720p/30 FPS）的同步RGB和五个G-buffer通道，包括恶劣天气和运动模糊变体。该数据集独特地推进了双向渲染：实现了野外环境的强大几何和材质分解，并促进了高保真G-buffer引导的视频生成。此外，为了在没有ground truth的情况下评估逆渲染的真实世界性能，我们提出了一种基于VLM的评估协议，测量语义、空间和时间一致性。实验表明，在我们的数据上微调的逆渲染器实现了卓越的跨数据集泛化和可控生成，而我们的VLM评估与人类判断强烈相关。结合我们的工具包，我们的正向渲染器允许用户使用文本提示从G-buffer中编辑AAA游戏的样式。

### 关键贡献
1. **大规模动态数据集**: 从AAA游戏中提取400万连续帧（720p/30 FPS）的同步RGB和五个G-buffer通道
2. **双向渲染**: 实现野外环境的强大几何和材质分解，促进高保真G-buffer引导的视频生成
3. **VLM评估协议**: 在没有ground truth的情况下评估逆渲染的真实世界性能
4. **卓越的泛化和可控生成**: 在我们的数据上微调的逆渲染器实现了卓越的性能
5. **工具包**: 允许用户使用文本提示从G-buffer中编辑AAA游戏的样式

## 核心技术

### 问题背景

**现实感和时间连贯性瓶颈**:
- 现有合成数据集的现实感和时间连贯性有限
- 生成式逆渲染和正向渲染扩展到真实场景的瓶颈
- 需要弥合持续的域差距

**挑战**:
- 缺乏大规模、高质量的真实世界数据
- 难以在没有ground truth的情况下评估真实世界性能
- 需要支持双向渲染（逆渲染 + 正向渲染）

### 数据集构建

**双屏拼接捕获方法**:
```
1. 捕获同步RGB和G-buffer
   - RGB：720p/30 FPS
   - G-buffer：5个通道（深度、法线、反照率等）

2. 双屏拼接
   - 将两个屏幕的输出拼接
   - 保持时间同步
   - 确保空间对齐

3. 数据提取
   - 从AAA游戏中提取
   - 视觉复杂场景
   - 多样化环境、视觉效果、天气

4. 数据规模
   - 400万连续帧
   - 同步RGB和G-buffer
   - 多样化场景、视觉效果、天气
```

**数据集特点**:
- 大规模：400万连续帧
- 高质量：720p/30 FPS
- 多样化：场景、视觉效果、环境、天气
- 同步：RGB和G-buffer时间同步
- 真实感：AAA游戏级别的视觉质量

### 双向渲染

**逆渲染（Inverse Rendering）**:
```
功能：从图像重建几何和材质

实现：
- 在我们的数据上微调
- 跨数据集泛化
- 可控生成

性能：
- 卓越的跨数据集泛化
- 强大的几何和材质分解
- 高保真重建
```

**正向渲染（Forward Rendering）**:
```
功能：从G-buffer生成RGB图像

实现：
- 文本提示控制
- 样式编辑
- 高保真生成

工具包：
- 允许用户从G-buffer编辑AAA游戏样式
- 文本提示控制
- 实时渲染
```

### VLM评估协议

**评估协议**:
```
目标：在没有ground truth的情况下评估真实世界性能

指标：
1. 语义一致性（Semantic Consistency）
   - VLM评估生成图像的语义一致性
   - 与人类判断强相关

2. 空间一致性（Spatial Consistency）
   - VLM评估空间结构的一致性
   - 几何一致性

3. 时间连贯性（Temporal Consistency）
   - VLM评估时间序列的一致性
   - 运动连贯性

优势：
- 无需ground truth
- 与人类判断强相关
- 多维度评估
```
