## 核心信息

### 摘要
视频扩散模型的最新进展使能够模拟交互环境的"世界模型"得以发展。然而，这些模型主要局限于单智能体设置，无法同时控制场景中的多个智能体。在本文中，我们解决了现有视频扩散模型中的动作绑定（action binding）的基本问题，这些模型难以将特定动作与对应的主题（subjects）关联起来。为此，我们提出了 ActionParty，一个用于生成视频游戏的可动作控制多主题世界模型。它引入了主题状态令牌（subject state tokens），即持久捕获场景中每个主题的状态的潜在变量。通过联合建模状态令牌和视频潜在表示（video latents）与空间偏向机制（spatial biasing mechanism），我们解耦了全局视频帧渲染与单独的动作控制主题更新。我们在 Melting Pot 基准上评估 ActionParty，展示了首个视频世界模型能够同时控制多达 7 个玩家，跨越 46 个多样化环境。我们的结果显示在动作跟随准确性和身份一致性方面有显著改善，同时能够通过复杂交互实现主题的鲁棒自回归跟踪。

### 关键贡献
1. **多智能体动作绑定**: 首个视频世界模型能够同时控制多个智能体
2. **主题状态令牌**: 持久捕获每个主题状态的空间偏向机制
3. **空间偏向机制**: 解耦全局渲染与个体动作控制
4. **多智能体控制**: 同时控制多达 7 个玩家
5. **动作跟随与身份一致性**: 在复杂交互中实现鲁棒跟踪

## 核心技术

### 问题背景

**单智能体世界模型的局限**:
- 现有的视频世界模型主要处理单智能体场景
- 无法同时控制场景中的多个智能体
- 动作绑定问题：难以将特定动作与对应的主题关联
- 缺乏多智能体交互的理解

**多智能体视频生成的挑战**:
- 需要同时跟踪和控制多个主题
- 主题间的交互关系复杂
- 全局渲染与个体动作控制的耦合
- 身份一致性的保持

### ActionParty 框架

**核心思想**:
通过主题状态令牌和空间偏向机制，实现多智能体动作绑定和联合渲染。

**技术组件**:

**1. 主题状态令牌（Subject State Tokens）**:
```
功能：持久捕获场景中每个主题的状态

实现：
- 每个主题对应一个状态令牌
- 状态令牌是持久变量，随时间更新
- 捕获主题的位置、姿态、动作等状态信息

优势：
- 解耦不同主题的状态
- 支持多智能体同时控制
- 保持身份一致性
```

**2. 空间偏向机制（Spatial Biasing Mechanism）**:
```
功能：解耦全局视频帧渲染与个体动作控制

实现：
- 联合建模状态令牌和视频潜在表示
- 空间偏向机制分离全局和局部信息
- 个体动作控制通过空间偏向注入

优势：
- 保持全局场景一致性
- 支持个体动作的独立性
- 避免动作冲突
```

**3. 动作绑定（Action Binding）**:
```
功能：将特定动作与对应的主题关联

实现：
- 主题状态令牌编码主题身份
- 动作输入通过主题令牌路由到对应主题
- 联合建模动作与状态

优势：
- 解决动作绑定问题
- 提高动作跟随准确性
- 支持多智能体交互
```

**4. 多智能体控制（Multi-Agent Control）**:
```
功能：同时控制多个智能体

实现：
- 多个主题状态令牌并行处理
- 每个主题独立接收动作输入
- 联合渲染多智能体场景

性能：
- 同时控制多达 7 个玩家
- 跨越 46 个多样化环境
- 鲁棒的身份一致性
```

## 实验结果

### 数据集与评估

**Melting Pot 基准**:
- 生成视频游戏的标准基准
- 包含多智能体交互场景
- 用于评估多智能体控制

**评估指标**:
- 动作跟随准确性（action-following accuracy）
- 身份一致性（identity consistency）
- 视频质量（video quality）

### 主要结果

**多智能体控制**:
- 首个视频世界模型能够同时控制多达 7 个玩家
- 跨越 46 个多样化环境
- 鲁棒的自回归跟踪

**性能提升**:
- 动作跟随准确性显著改善
- 身份一致性显著改善
- 在复杂交互中保持鲁棒性

**与基线对比**:
- 在多智能体任务上大幅超越单智能体方法
- 在视频质量上与单智能体方法相当
- 在身份一致性上大幅提升
